额度条 1.3.0（macOS 通用版）

使用条件：macOS 13 或更新版本；支持 Apple 芯片和 Intel。
这是独立菜单栏应用，不需要宠物或 ChatGPT 桌面窗口保持打开。
需要另外安装可信的 Codex CLI，并使用你自己的 ChatGPT 账号登录。
本安装包不包含任何人的账号、Cookie、Token 或 Codex CLI。

1. 按 OpenAI 官方文档安装 Codex CLI：https://learn.chatgpt.com/docs/codex/cli
2. 在终端执行 codex login，完成你自己的登录。
3. 将「额度条.app」拖入「应用程序」，然后打开。
4. 若提示找不到 CLI，在终端执行 which codex，再在菜单中点击「选择 Codex CLI…」选择该文件。
   nvm/asdf 等版本管理器用户也可通过这个入口选择对应版本。
5. 菜单中可分别开关 5 小时、每周用量，也可关闭或恢复桌面悬浮条。

语言：点击菜单栏 →「语言 / Language」→「简体中文」或「English」，立即切换并记住选择。

显示的是剩余额度，时间与日期使用北京时间。每 60 秒刷新。
重置券分为「5 小时重置次数」「每周重置次数」「完全重置次数」，独立计数。
只有 1 张完全重置券时显示 0、0、1。接口明细不全时显示「未提供明细」。
此应用仅查询，不执行重置，也不调用模型生成内容。
账号或 CLI 版本未提供的数据将显示未知；只用 API Key 登录不保证提供套餐额度。

本地测试版使用 ad-hoc 签名，尚未取得 Apple Developer ID 签名及公证。
互联网下载后可能被 Gatekeeper 拦截，不应关闭系统安全保护。
如系统不允许打开，请等待发布者提供完成 Apple 签名和公证的版本。
开发者也可查看源码并自行构建；无需 Python 或 Xcode 来运行已打包应用。

电脑重启后从「应用程序」重新打开；本版本不设置开机自启。
退出：点击菜单栏中的「退出额度条」。显示设置保存在本机，不随安装包分发。
